# Images needed to finish the campus

The list comes from the full-campus OpenStreetMap layout (`data/campus_full.features.json`). Everything that repeats
is drawn once and reused. Roads, lawns, hedges, trees, flags, lamps and the circles are cut from the images we
already have, so they need **no new images**.

## Rules for every image
1. **Style reference:** attach `art/reference_main.png` and `art/reference_fd2.png`. Ask for "the exact same art style,
   palette, outline weight, 16 px tile scale and 3/4 top-down view".
2. **Scale:** match the references. A two-storey wall is about 48 px tall, a road is 3–4 tiles (50–64 px) wide, and a
   person is about 16 px tall. The target sizes below are given in px.
3. **Kit images** (buildings that repeat): one building, centred, on **plain flat grass** with nothing touching
   the edges. Entrance facing **down (south)** unless noted. This keeps the cut-out clean.
4. **Area images** (unique places): extend an existing image ("extend canvas" / outpaint) wherever possible, so
   seams match, the same way FD2 was done.
5. No people, no text, no watermark, no UI. PNG at the original resolution, with no upscaling or filters.
6. **Also send me:** 3–5 Street View screenshots plus one satellite crop of the place, so I can check the result
   and place it to match the satellite view.
